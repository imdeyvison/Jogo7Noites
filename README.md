# 7 Noites

Este projeto trata-se de um jogo desenvolvido na engine **RPG Maker MZ** e possui o foco em mitigar as dificuldades dos estudantes do 1º ano do Ensino Médio na disciplina de Matemática especificamente na Unidade temática de Probabilidade e Estatística no IFPI Campus Piripiri. 

---

## 📋 Pré-requisitos

Para abrir, editar e testar o projeto localmente, você precisará de:

* **[RPG Maker MZ](https://store.steampowered.com/app/1096900/RPG_Maker_MZ/)** (versão 1.0.0 ou superior recomendada).
* **Git** instalado na sua máquina (caso vá clonar o repositório via linha de comando).

---

## ⚙️ Instruções de Instalação

### 1. Clonar o Repositório

Abra o seu terminal/prompt de comando e execute:

```bash
git clone https://github.com/imdeyvison/Jogo7Noites.git
```

*Caso prefira, você também pode baixar o projeto compactado em `.zip` clicando no botão **Code > Download ZIP** no topo da página do GitHub e extraindo o arquivo no seu computador.*

---

## 🎮 Como Executar no RPG Maker MZ

1. **Abra o RPG Maker MZ.**
2. No menu superior, clique em **Arquivo (File)** > **Abrir Projeto... (Open Project...)** *(ou use o atalho `Ctrl + O`)*.
3. Navegue até a pasta onde o repositório foi clonado/extraído.
4. Selecione o arquivo de projeto do RPG Maker MZ (`game.rmmzproject`) e clique em **Abrir**.
5. Para testar o jogo dentro da engine, clique no botão **Play / Testar Jogo** no menu principal ou pressione as teclas  `Ctrl + R`.

---

## 📁 Estrutura de Pastas

```text
Jogo7Noites/
├── audio/          # Efeitos sonoros e músicas (BGM, BGS, SE, ME)
├── data/           # Bancos de dados e eventos (.json)
├── fonts/          # Fontes utilizadas pelo jogo
├── icon/           # Ícone do projeto
├── img/            # Recursos visuais (Tilesets, Personagens, UI)
├── js/             # Scripts e plugins em JavaScript
└── game.rmmzproject # Arquivo principal do projeto
```

---

## 🚀 Como Fazer o Build / Exportar o Jogo

Se deseja gerar o executável final para distribuição:

1. No RPG Maker MZ, vá em **Arquivo (File)** > **Implantação... (Deployment...)**.
2. Escolha a plataforma de destino (Windows, macOS, Web, etc.).
3. Selecione a pasta de saída e marque as opções desejadas (como *Compactar arquivos de jogo*).
4. Clique em **OK** para realizar o build do projeto.
